# Issue #1. Баланс группы не сходится на копейку

**Тип:** bug · **Автор:** Вика (пользователь) · **Метки:** `good first issue`

> Скинулись с Аней и Борей на пиццу, 1000 ₽, платила Аня. Приложение показывает:
>
> ```
> Аня    666.67 ₽
> Боря  -333.33 ₽
> Вика  -333.33 ₽
> ```
>
> 666.67 − 333.33 − 333.33 = 0.01. Куда делась копейка?? Мы с Борей перевели
> Ане по 333.33, а она говорит, что ей всё ещё должны 1 копейку 😅

**Как воспроизвести:**

```bash
skinemsya init "Пицца"
skinemsya member add Аня Боря Вика
skinemsya expense add --payer Аня --amount 1000
skinemsya balance
```

**Ожидание:** сумма балансов всегда равна нулю.
