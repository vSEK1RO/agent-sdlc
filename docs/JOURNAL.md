# Журнал работы с агентом

Короткие записи о том, что пошло не так (или неожиданно хорошо).
Не нужно писать роман: 2–4 строки на запись. Журнал — главный материал
для защиты на паре 4.

**Инструмент и модель:** <!-- например: Claude Code / Sonnet, Qwen Code, Cursor, OpenCode + DeepSeek -->

## Шаблон записи

```
### [пара N] Короткий заголовок
- Что просил:
- Что сделал агент:
- Почему это проблема / как заметил:
- Что изменил в процессе (промпт, AGENTS.md, тест, хук), чтобы не повторилось:
```
